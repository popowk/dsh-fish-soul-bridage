SnowLuma v2.4.2 integration placeholder (source repository)

The user-supplied SnowLuma_v2.4.2_Fix.zip includes a patched Windows runtime
and selected overlay web assets, but not the complete SnowLuma WebUI assets,
including CSS modules or the referenced binary redistribution license.

This public source repository deliberately does NOT commit these vendor
binaries. Set SNOWLUMA_DIR to an existing, licensed, COMPLETE SnowLuma install.
The Windows bundle delivered separately contains the supplied overlay and
still requires an authorized complete installation for a working WebUI.

Do not run a partial overlay as if it were the full WebUI distribution.
